# Meeting walkthrough — PrintWorks demo (≈ 15 minutes)

Setup: two browser windows side by side — left: storefront, right: CMS `/admin` (already logged in, demo login
`admin@printwor-ks.com` / `printworks2026`). Optional: **Konfigurimet → Të dhënat demo → Rivendos** beforehand so the
dashboard numbers are fresh.

## 1. First impression (2 min) — storefront home
- Dark hero "Perfection Printed." with their own packaging photography, purple brand, chevron logo, SQ/EN switch.
- Scroll: capabilities (proof in 24 h · from 100 pcs · offset, digital, flexo, HP Indigo under one roof) → the six
  ranges → bestsellers with "from €x / pc" → industries (Food & Beverage, FMCG, Cosmetics, Cleaning, Publishing) →
  how it works (configure → upload artwork → proof → production) → their real technology (Manroland B1, HP Indigo,
  8-colour LED UV flexo, Heidelberg Versafire, die-cutting, folder gluing, UV coating, QC) → numbers (2020 · 14
  countries · 2,500 m²) → projects → partner brands → FAQ → "request a quote".
- Switch to **English** and back — everything translates, including product data.

## 2. Ordering print like a customer (4 min)
- Products → **Paketime ushqimore** → filters (price per piece, lead time, minimum order).
- Open the **octagonal pizza box**: choose Ø 33 cm, print inside + outside, pick **1,000 pcs** — the unit price drops
  live from the tier table; add **professional design (+€45)** or upload a PDF; add to cart.
- Open **food labels on rolls**: 5,000 pcs, white PP, gloss varnish, upload artwork (file name + preview).
- Cart: artwork status per line, free delivery progress, **total excl. VAT → VAT 18 % → total**, code `PRINT10`.
- Checkout as a business: company, **NUI**, PO number, bank transfer with pro-forma → order confirmation with the
  "proof within 24 h → approve → production → delivery" timeline.
- **Request a quote** for a custom chocolate drawer box: specs, finishes, deadline, files.

## 3. The "wow" moment (1 min)
- The order appears **instantly** in the CMS window (notification, toast, dashboard); the quote request lands in
  **Kontaktet** with all its specs.

## 4. Running the print shop in the CMS (6 min)
- **Përmbledhje** — revenue (net and gross), orders, average order, orders waiting for files, proofs awaiting approval.
- **Porositë** → the new order: **Prepress & provë** card — mark the file received, send proof v1, the customer asks
  for changes, send v2, approve → "Nis prodhimin" → ship → delivered; print the **invoice / pro-forma** (NUI, TVSH 18 %).
- **Kontaktet** → the quote request → **Krijo ofertë** (net prices + VAT) → send.
- **Produktet** → a product: the **quantity-tier price editor**, minimum order, quantity step, design-service fee,
  options, two languages, photos, SEO → save → the storefront updates.
- **Online Store → Editor** — homepage builder: edit the hero, reorder sections, hide one — live preview on desktop /
  tablet / mobile, publish with versions.
- **Konfigurimet** — company data, VAT 18 % and "prices excl. VAT", delivery zones Kosovo / region, payments, staff &
  roles, brand colour.

## 5. Close (2 min)
- Everything they saw is editable by their own staff, in Albanian or English.
- Production version: their domain printwor-ks.com, real file storage for artwork and proof PDFs, Kosovo card-payment
  gateway, ATK fiscalisation, e-mail notifications, Google indexing in both languages.

Tip: if anything gets messy during the demo, **Konfigurimet → Të dhënat demo → Rivendos** restores everything.
